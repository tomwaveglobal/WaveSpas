# SEO documentation has moved

The WaveSpas SEO analysis — opportunity lists, the Week 1 deliverables plan, and the GSC/GA4 export
runbook — now lives in the Wave CRM repository:

    wave-crm/docs/seo/

Wave CRM is the system of record for SEO across the Wave storefronts. It crawls them, tracks issues
across crawls as findings, and holds the keyword and opportunity data. This repository is where the
fixes get applied — Liquid templates, meta tags, schema — but not where findings are tracked.

Theme changes that resolve an SEO finding should be recorded against that finding in Wave CRM, not
documented here.
